# Factory

Автоматизация заводского производства в терминале: добыча ресурсов,
производство продуктов, заказы городов и логистика между ними.

[![Лицензия: GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)
![Rust](https://img.shields.io/badge/Rust-1.85+-orange.svg)

## Описание

Игрок автоматизирует заводское производство: добывает исходные компоненты
на добывающих фабриках, производит продукты на собственных заводах и
выполняет заказы городов, организуя логистику по дорогам, ЖД, воздуху
и воде.

Ключевые механики:

- **Глобальная карта** — сетка с городами, заводами игрока и добывающими
  фабриками; прокладка логистических маршрутов.
- **Завод как набор блоков** — на карте завод представлен точками-блоками,
  проектирование и конвейеры — на отдельном экране производства.
- **Экономика** — заказы городов (основной доход) + свободная торговля;
  штраф за просрочку заказа.
- **Города-производители** — города производят уникальные компоненты,
  которые игрок не может создать сам (аккумуляторы, микросхемы, стекло).
- **Data-driven рецепты** — цепочки производства описываются TOML-данными
  и балансируются без изменения кода.

## Быстрый старт

Требуется Rust (edition 2024, MSRV 1.85+).

```sh
# сборка и запуск TUI
cargo run -p factory-tui
```

Выход из игры — клавиша `q`. Полная раскладка управления — в
[документации](docs/ru/08-tech.md).

> Текущий статус: ранняя разработка. TUI пока показывает заглушку —
> интерфейс реализуется вместе с моделью `Map` в `factory-core`.

## Структура репозитория

```
crates/
├── factory-core/   # игровая логика (без зависимостей от интерфейса)
└── factory-tui/    # терминальный интерфейс (ratatui + crossterm)
docs/               # документация (по языкам: ru/ сейчас, en/ позже)
assets/data/        # исходные данные игры (каталоги, рецепты, переводы)
LICENSE             # GNU GPL-3.0
```
