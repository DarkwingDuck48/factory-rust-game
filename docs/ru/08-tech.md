# Технологии и код

## Структура кода

- Воркспейс Cargo, все крейты в `./crates`.
- `./crates/factory-core` — игровая логика (без зависимости от интерфейса).
- `./crates/factory-tui` — TUI-интерфейс.
- `./crates/factory-edit` — CLI-инструмент для работы с данными
  (создание, валидация, рефакторинг; см. [Данные](07-data.md)).

### Модульная структура `factory-core` (текущее состояние)

```
src/
├── lib.rs                      # публичный экспорт
└── map/
    ├── map.rs                  # сборка модулей карты
    ├── position.rs             # Position, Direction
    └── mapobjects/
        ├── mapobjects.rs       # enum MapObject
        ├── city.rs             # City
        ├── factory.rs          # PlayerFactory, PlayerFactoryBlock, ExtractionFactory
        └── resources.rs        # Resource (временный enum)
```

Слои: объекты не знают о карте как о целом; карта (будет) держит сетку
и коллекцию объектов.

## Технологический стек

- **Чистый Rust, без игровых движков.** Для TUI-игры движок не нужен:
  «движком» выступает связка терминальной библиотеки и собственного
  игрового цикла. Это идиоматичный подход, а не компромисс.

### `factory-core` (логика, без зависимостей от интерфейса)

- `serde` + `toml` — data-driven рецепты (TOML) и сейвы.
- `rand` — генерация карты, случайные аспекты (например, выбор
  уникального рецепта города).
- `thiserror` — ошибки домена.
- Рецепты описываются **данными в TOML-файлах**, а не зашиваются в код.
- Загрузчик данных: читает `data/`, валидирует (отчёт со всеми ошибками
  - подсказки `did you mean`), вычисляет тиры.
- Запись/правка TOML — через API `toml_edit` (сохраняет комментарии
  и порядок таблиц); используется `factory-edit`.

### `factory-tui` (интерфейс)

- `ratatui` — рендеринг TUI: layout, виджеты, `Canvas` для карты.
- `crossterm` — ввод с клавиатуры, цикл событий.
- `anyhow` — обработка ошибок в бинарнике.
- Логирование в **файл** (`log` + аппендер): терминал занят TUI.

### Текущее состояние интерфейса

Экран глобальной карты реализован: генерация карты по seed, сайдбар
городов с выбором (Tab), легенда. На карте есть **курсор**: `hjkl`/
стрелки — шаг курсора (через `Position::step`), его координаты `x`/`y`
постоянно показываются в правой части заголовка рамки карты, сам курсор
подсвечивается белой ячейкой. Камера следует за курсором (минимальный
пан, когда он уходит за край) и дополнительно панорамируется вручную.
Далее: зум по точке → экран производства.

### Игровой цикл

- Фиксированный тик симуляции в `factory-core` с единым вызовом
  `tick(dt)`; TUI вызывает его и рендерит состояние.
- Ожидание ввода через `crossterm::event::poll(timeout)` — без busy-wait.
- Буфер кадра ratatui диффается между кадрами — перерисовываются только
  изменённые ячейки.
- Логика не знает про терминал: всё тестируется юнит-тестами в `factory-core`.

### Ввод

- Только клавиатура, **без поддержки мыши**; раскладка — vim-стиль
  и префикс-команды (подробно в разделе «Управление»).

### Рендеринг

- Сетка завода и тайлы карты — собственный «текстовый буфер»
  (2D-массив ячеек символов и цветов).
- `Canvas` — для контуров и линий маршрутов на глобальной карте.
- Палитра с фолбэком (16/256/truecolor), простые символы юникода.

## Управление

- **Только клавиатура, без поддержки мыши.**
- Раскладка **vim-стиль** + **префикс-команды** (leader `Space`),
  модальные режимы.

### Режимы

- `Навигация` — по умолчанию: движение `hjkl`, `gg`/`G`, `0`/`$`,
  метки (`m <буква>` / `' <буква>`), `Enter` — открыть объект
  под курсором (город/завод).
- `Меню/список` — `j`/`k`, `Enter`, `Esc` (здания, заказы, сейвы).
- `Размещение/рисование` — движение `hjkl`, `Enter` фиксирует,
  `Esc` отменяет (здания, конвейеры, маршруты).
- `Ввод` — для имён и чисел, строка ввода **внизу экрана**
  (по аналогии с vim `:`).

### Префикс-команды (`Space` …)

| Ключ                  | Действие                                       |
| --------------------- | ---------------------------------------------- |
| `Space g` / `Space f` | переключение экранов: глобальная карта / завод |
| `Space b`             | построить (меню зданий)                        |
| `Space c`             | прокладка конвейера/соединения                 |
| `Space r`             | маршрут на глобальной карте                    |
| `Space s` / `Space l` | сохранить / загрузить                          |
| `Space p`             | пауза                                          |
| `Space q`             | выход                                          |
| `Space ?`             | помощь по раскладке                            |

### Навигация камеры

- Курсор карты: `hjkl`/стрелки — шаг на клетку (`Position::step` —
  тот же механизм, что и для будущих дорог/маршрутов); камера следует
  за курсором, не давая ему уйти за край экрана.
- Пан камеры без движения курсора: `Shift+hjkl` — пальцы не уходят
  с домашнего ряда.
- Ctrl-комбинации ненадёжны: `Ctrl+h` в части терминалов = backspace,
  `Ctrl+b` перехватывается tmux.
