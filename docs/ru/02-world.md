# Мир и карта

## Карта

- Карта — **сетка** (клетки).
- На карте расположены: города, заводы игрока, добывающие фабрики.
- По карте прокладываются логистические маршруты.

## Координатная система (решение)

- Позиция на карте — `Position { x, y }`; координаты целочисленные.
- Конвенция осей — **ряды/колонки**: `x` — колонка (растёт вправо),
  `y` — ряд (растёт **вниз**). Это совпадает с устройством терминала:
  движение вверх по экрану = уменьшение `y`.
- Направления — enum `Direction` (`Up`, `Down`, `Left`, `Right`);
  переход к соседней клетке — метод `step(direction)`. Один механизм
  используется и для курсора игрока, и для прокладки дорог/конвейеров,
  и для будущих маршрутов.
- **Позиция хранится внутри каждого объекта карты** (`map_position`).
  Карта — коллекция объектов; отдельный реестр «клетка → объект»
  не ведётся (при необходимости — индекс поверх коллекции).

## Объекты карты

- `MapObject` — enum-тег: `City`, `PlayerFactory`, `ExtractionFactory`,
  варианты несут данные конкретных типов.
- У каждого объекта своя `map_position`:
  - город и добывающая фабрика — клетка, где объект стоит;
  - завод — каждая его точка (блок) занимает свою клетку (см.
    [Завод и производство](03-factory.md)).

## Добывающие фабрики (источники компонентов)

**Отдельный тип объекта** — не являются заводами игрока, стоят на карте
сами по себе. Поставляют исходные компоненты:

| Фабрика                    | Что добывает                |
| -------------------------- | --------------------------- |
| Карьер                     | Камень                      |
| Песчаный карьер            | Песок (Т0)                  |
| Лесопилка                  | Лес (дерево)                |
| Шахта                      | Металлы (железо, медь) — Т2 |
| Шахта (после исследований) | Уголь (Т2), литий (Т2)      |

В коде фабрика представлена типом `ExtractionFactory { resource, map_position }`.

## Ресурсы (текущее состояние кода)

В `factory-core` пока живёт временный enum `Resource`
(`Wood`, `Iron`, `Stone`, `Sand`) — черновой набор для разработки модели.
Финальный каталог ресурсов будет data-driven (`resources.toml`, см.
[Данные](07-data.md)).
